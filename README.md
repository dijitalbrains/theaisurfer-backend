## Description

**theaisurfer-backend** - Central authentication and authorization platform for multiple child products (remixer, northstar, etc.)

### Features
- JWT-based authentication with refresh tokens
- Multi-project access control
- User registration and login
- Project-based authorization
- Swagger API documentation

### Tech Stack
- NestJS (latest)
- TypeScript
- TypeORM with MySQL
- Passport JWT
- Swagger/OpenAPI

## Environment Setup

1. Create a `.env` file in the project root (copy from `.env.example`):

```bash
# Database Configuration
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=
DB_NAME=theaisurfer

# JWT Configuration
JWT_SECRET=your-secret-key-change-this-in-production
JWT_ACCESS_EXPIRATION=15m
JWT_REFRESH_SECRET=your-refresh-secret-key-change-this-in-production
JWT_REFRESH_EXPIRATION=7d

# Application Configuration
PORT=3000
```

2. Create MySQL database:
```sql
CREATE DATABASE theaisurfer;
```

3. Run database migrations:
```bash
$ npm run migration:run
```

For more details on migrations, see [MIGRATIONS.md](MIGRATIONS.md)

## Project setup

```bash
$ npm install
```

## Database Setup

Make sure MySQL is running and create the database:

```sql
CREATE DATABASE theaisurfer;
```

Then run the seed script to populate with test data:

```bash
$ npm run seed
```

This will create:
- 3 test users (john.doe@example.com, jane.smith@example.com, bob.johnson@example.com)
- 2 test projects (remixer, northstar)
- User-project access relationships

All test users have password: `password123`

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

The API will be available at `http://localhost:3000`
Swagger documentation will be available at `http://localhost:3000/api`

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
